| 저자 | Idan Shenfeld, Mehul Damani, Jonas Hübotter, Pulkit Agrawal |
| 소속 | MIT (Improbable AI Lab), ETH Zurich |

이 글은 **LLM을 막 공부하기 시작한 사람**을 대상으로 한다. 전문 용어는 처음 나올 때 풀어 쓰고, 수식은 마지막 부록으로 뺐다.

---

## 0. 세 줄 요약

1. LLM에게 새 기술을 가르치면(파인튜닝) **원래 잘하던 것을 잊어버리는** 문제가 있다.
2. SDFT는 정답 예시를 **그대로 베끼게 하지 않는다.** 대신 "예시를 본 나 자신"을 선생님으로 삼아, **내가 직접 쓴 답을 첨삭받는** 방식으로 가르친다.
3. 그 결과 새 기술은 **더 잘** 배우고, 기존 능력은 **거의 그대로** 남았다.

## 1. 먼저 알아둘 용어

| 용어 | 쉬운 설명 |
|---|---|
| **사전학습 (pre-training)** | 인터넷 규모의 텍스트로 "다음 단어 맞히기"를 반복해 언어와 상식을 익히는 단계. 모델의 기초 체력이다 |
| **파인튜닝 (fine-tuning)** | 사전학습된 모델에게 특정 일(의료 상담, 도구 사용 등)을 추가로 가르치는 단계 |
| **SFT (Supervised Fine-Tuning)** | 가장 흔한 파인튜닝. "질문 → 모범 답안" 쌍을 주고 **모범 답안을 한 글자씩 똑같이 따라 쓰도록** 학습시킨다 |
| **파국적 망각 (catastrophic forgetting)** | 새 것을 배우다가 예전에 할 줄 알던 것을 잊어버리는 현상. 신경망은 같은 가중치(파라미터)를 계속 고쳐 쓰기 때문에 생긴다 |
| **In-context learning (ICL)** | 가중치는 그대로 둔 채 **프롬프트 안에 예시를 보여주기만 해도** 모델이 그 방식을 따라 하는 능력. 큰 모델일수록 잘한다 |
| **증류 (distillation)** | "선생님 모델"의 답변 경향을 "학생 모델"이 따라 하도록 학습시키는 것 |
| **온폴리시 / 오프폴리시** | 학생이 **자기가 직접 만든 답**으로 배우면 온폴리시(on-policy), **남이 만든 답**으로 배우면 오프폴리시(off-policy) |
| **KL divergence** | 두 확률 분포가 얼마나 다른지 재는 값. 여기서는 "두 모델이 다음 단어를 고르는 경향이 얼마나 다른가"로 이해하면 된다. 0이면 똑같다 |

## 2. 문제 — 가르치면 잊는다

### 2.1 실제로 얼마나 잊나

논문의 실험 하나를 보자. Qwen2.5-7B-Instruct 모델에게 **화학 문제 풀이**를 SFT로 가르쳤다.

| | 화학 문제 | 지시 따르기 (IFEval) | 코딩 (HumanEval) |
|---|---|---|---|
| 원래 모델 | 32.1 | 74.3 | 65.8 |
| SFT 후 | **66.2** ↑ | **35.3** ↓↓ | **54.8** ↓ |

화학 점수는 두 배가 됐지만, **"시키는 대로 하기" 능력이 절반으로 떨어졌다.** 코딩 실력도 줄었다. 화학을 배웠을 뿐인데 말이다.

### 2.2 왜 잊을까 — "남의 답안지를 베끼기"

SFT가 하는 일을 비유하면 이렇다.

> 학생에게 **다른 사람이 쓴 모범 답안**을 주고, **토씨 하나 틀리지 않게 베껴 쓰라**고 시킨다.

모범 답안은 학생의 평소 말투나 사고방식과 다르다. 그걸 억지로 똑같이 쓰려다 보니 학생의 "머릿속 습관" 전체가 크게 바뀐다. 그 과정에서 원래 잘하던 것들이 망가진다.

이 논문의 제1저자가 이전 논문 **RL's Razor**(2025)에서 보인 것이 바로 이 점이다.

- 망각의 크기는 **"원래 모델에서 얼마나 멀어졌는가"**(KL divergence)로 꽤 정확하게 예측된다.
- 강화학습(RL)이 SFT보다 덜 잊는 이유는, RL은 **자기가 만든 답**으로 배우므로(온폴리시) 원래 모습에서 **가장 조금 벗어나는** 해답을 찾기 때문이다.

### 2.3 그럼 RL을 쓰면 되지 않나?

RL을 하려면 **점수표(보상)**가 필요하다. "이 답은 10점, 저 답은 3점"을 자동으로 매겨 줄 수 있어야 한다. 그런데 실무에서 가진 것은 대개 **모범 답안(데모)** 뿐이다. 의사의 답변 예시, 도구 사용 예시, 전문가 풀이 같은 것들이다.

그래서 논문의 질문은 이것이다.

> **점수표 없이 모범 답안만 있어도, RL처럼 "내 답으로 배우는" 방식을 쓸 수 있을까?**

## 3. SDFT의 아이디어 — "커닝 페이퍼를 본 나"가 선생님

### 3.1 핵심 관찰

큰 LLM은 in-context learning을 잘한다. 프롬프트에 모범 답안을 하나 보여주고 "이걸 참고해서 네 방식으로 답해 봐"라고 하면, **꽤 잘 푼다.**

논문에서 확인한 수치:

| 도구 사용 과제 (ToolAlpaca) | 정답률 |
|---|---|
| 그냥 물어봤을 때 | 42% |
| 모범 답안을 프롬프트에 보여줬을 때 | **100%** |

그렇다면 **"모범 답안을 본 나"는 이미 좋은 선생님**이다. 게다가 이 선생님은 **나 자신**이라서 말투와 사고방식이 나와 똑같다.

### 3.2 학습 과정 한 스텝

```
 ① 질문만 학생에게 준다
      학생(=모델)이 스스로 답을 쓴다           ← "내 답" (온폴리시)

 ② 같은 질문 + 모범 답안을 선생님에게 준다
      선생님(=같은 모델, 모범 답안을 본 상태)

 ③ 학생이 쓴 답을 한 단어씩 보면서 선생님에게 묻는다
      "너라면 이 자리에 어떤 단어를 얼마나 쓰겠어?"

 ④ 학생의 단어 선택 경향을 선생님 쪽으로 조금 고친다

 ⑤ 선생님도 학생을 아주 천천히 따라 업데이트한다 (EMA)
```

비유로 말하면 이렇다.

> **SFT**: 남의 답안지를 통째로 베껴 쓴다.
> **SDFT**: 내가 먼저 답을 쓴다. 그러면 **모범 답안을 옆에 펴 둔 또 다른 나**가 "이 부분은 이렇게 쓰는 게 낫겠다"고 **첨삭**해 준다.

### 3.3 선생님에게 주는 프롬프트

논문에 실린 실제 형식이다.

```
<질문>
This is an example for a response to the question:
<모범 답안>
Now answer with a response of your own, including the thinking process:
```

"**네 방식으로** 답하라"는 마지막 문장이 중요하다. 선생님은 모범 답안을 **베끼지 않고**, 그 내용을 참고해서 **자기 말투로** 답한다. 그래서 선생님의 답은 **내용은 정확하지만 스타일은 원래 모델과 같다.**

### 3.4 왜 이게 덜 잊는가

원래 모델에서 얼마나 멀어졌는지를 KL divergence로 재면:

| 모델 | 원래 모델과의 거리 (KL) |
|---|---|
| SFT로 학습한 모델 | 1.26 |
| 모범 답안을 본 선생님 | **0.68** |

선생님은 과제를 100% 풀면서도, SFT 결과물보다 원래 모델에 **거의 두 배 가깝다.** 학생은 이 선생님을 따라가므로 원래 모습에서 멀리 벗어나지 않는다. 멀리 벗어나지 않으니 덜 잊는다. 2.2의 RL's Razor 논리를 그대로 활용한 것이다.

### 3.5 선생님은 누구인가 — 너무 고정해도, 너무 따라가도 안 된다

선생님 모델의 가중치를 어떻게 둘지도 실험했다.

| 선생님 설정 | 결과 |
|---|---|
| 원래 모델로 **고정** | 안정적이지만 성능이 낮다. 학생이 새로 배운 것을 선생님이 모른다 |
| 현재 학생과 **똑같이** | 학습이 불안정해져 망가진다. 학생의 작은 실수를 선생님이 그대로 따라 하며 증폭된다 |
| 학생을 **아주 천천히** 따라감 (EMA) | **채택**. 매 스텝 학생 쪽으로 1%씩만 움직인다 |

EMA(지수이동평균)는 "최근 값에 조금씩만 반영하는 평균"이다. 선생님이 학생의 발전을 반영하되, 순간적인 흔들림에는 휘둘리지 않게 해 준다.

## 4. 실험 결과

### 4.1 새 기술 배우기 — 세 가지 과제

Qwen2.5-7B-Instruct로 세 가지 과제를 각각 학습했다.

- **과학**: 화학 문제 풀이
- **도구 사용**: API를 올바르게 호출하기
- **의료**: 의학 질문에 답하기

"기존 능력"은 상식 추론, 사실성, 지식, 지시 따르기, 코딩 등 6개 벤치마크의 평균이다. 원래 모델은 **65.5**다.

| 과제 | 방법 | 새 과제 점수 | 기존 능력 평균 |
|---|---|---|---|
| 과학 (원래 32.1) | SFT | 66.2 | 53.4 |
| | **SDFT** | **70.2** | **64.5** |
| 도구 사용 (원래 42.9) | SFT | 63.2 | 56.0 |
| | **SDFT** | **70.6** | **65.4** |
| 의료 (원래 30.1) | SFT | 35.5 | 60.2 |
| | **SDFT** | **40.2** | **65.4** |

이 표에서 가장 놀라운 점은 **양쪽 모두에서 이긴다**는 것이다. 보통 망각을 줄이는 기법은 "덜 잊는 대신 덜 배운다"는 대가를 치른다. SDFT는 새 과제도 **더 잘** 배우고, 기존 능력도 **거의 그대로** 지킨다.

논문은 다른 비교 방법 두 가지도 함께 실험했다.

- **DFT**: SFT 데이터를 온폴리시처럼 보정해서 쓰는 방법
- **SFT 후 복구 학습**: SFT로 배운 뒤 원래 모델을 선생님으로 한 번 더 증류하는 방법

둘 다 SFT보다는 덜 잊지만, 새 과제와 기존 능력을 **동시에** SDFT만큼 잘 지킨 경우는 없었다.

### 4.2 새로운 지식 넣기

모델이 학습할 때는 존재하지 않았던 **2025년 자연재해에 관한 위키 문서 9개**(약 20만 토큰)를 가르쳤다.

| 방법 | 엄격 채점 | 너그러운 채점 | 간접 질문 |
|---|---|---|---|
| 원래 모델 | 0 | 0 | 0 |
| 문서를 그대로 더 학습 (CPT) | 9 | 37 | 7 |
| 문답 쌍으로 SFT | 80 | 95 | 80 |
| **SDFT** | **89** | **100** | **98** |
| 정답 문서를 찾아서 보여줌 (RAG, 상한선) | 91 | 100 | 100 |

"간접 질문"은 문서에 직접 나오지 않는, 조합이 필요한 질문이다. 예를 들어 "2025년에 국제 인도적 지원이 필요했던 나라는?" 같은 것이다. SFT는 80점, SDFT는 **98점**이다. SDFT가 지식을 **외운 게 아니라 이해해서 다른 질문에도 쓸 수 있게** 넣었다는 뜻이다. 정답 문서를 매번 찾아서 보여주는 RAG에 거의 근접한다.

### 4.3 여러 기술을 차례로 배우기

한 모델에게 **도구 사용 → 과학 → 의료**를 순서대로 가르쳤다.

- **SFT**: 다음 과제를 배우기 시작하면 바로 앞 과제 실력이 떨어진다. 성적이 오르락내리락한다.
- **SDFT**: 세 기술이 **차곡차곡 쌓인다.**

"평생 배우는 모델", 즉 **지속학습(continual learning)**에 가까운 모습이다. 논문 제목이 여기서 나왔다.

### 4.4 답만 있고 풀이가 없는 데이터

실무에는 "정답은 있는데 풀이 과정은 없는" 데이터가 많다. 추론 모델(Olmo-3-7B-Think)에게 의료 문제를 **답만** 주고 가르쳤다.

| 방법 | 정확도 | 평균 답변 길이 |
|---|---|---|
| 원래 모델 | 31.2% | 4,612 토큰 |
| SFT | **23.5%** ↓ | 3,273 토큰 |
| **SDFT** | **43.7%** ↑ | 4,180 토큰 |

SFT는 짧은 정답만 외우다 보니 **생각하는 습관을 잃고 오히려 성능이 떨어졌다.** SDFT에서는 선생님이 정답을 본 상태로 **자기 방식대로 풀이를 쓰므로**, 학생은 추론 습관을 유지하면서 정답 쪽으로 이끌려 간다.

### 4.5 모델 크기의 영향

과학 과제에서 SDFT가 SFT보다 몇 점 나은지:

| 모델 크기 | SDFT − SFT |
|---|---|
| 3B | **−3.3** (오히려 나쁨) |
| 7B | +4.0 |
| 14B | **+6.9** |

SDFT는 모델의 in-context learning 능력에 기대는 방법이다. **작은 모델은 모범 답안을 보여줘도 잘 따라 하지 못하므로** 선생님 역할을 못 한다. 반대로 모델이 클수록 효과가 커진다.

### 4.6 꼭 "내 답"으로 배워야 하나?

"선생님이 좋으면 됐지, 굳이 학생이 직접 답을 써야 하나?"라는 질문도 실험했다. 선생님이 쓴 답을 SFT로 베끼게 하거나, 선생님 출력을 미리 뽑아 두고 따라 하게 하면 SFT보다는 낫지만 **SDFT보다는 일관되게 못하다.** 핵심은 좋은 선생님만이 아니라 **내가 쓴 답으로 배우는 것**(온폴리시)이다.

| 한계 | 설명 |
|---|---|
| **비용** | 매번 학생이 답을 생성해야 하므로 SFT보다 계산량 약 **2.5배**, 학습 시간 약 **4배** |
| **작은 모델에서는 안 됨** | 3B에서는 SFT보다 나빴다. 7B 이상에서 의미가 있다 |
| **큰 변화는 못 가르침** | 선생님이 원래 모델과 가까워야 하므로, 예를 들어 "생각 과정을 전혀 안 쓰던 모델"을 "길게 추론하는 모델"로 바꾸는 식의 **근본적인 변화**는 어려웠다. 원래 모델에서 멀리 가지 않는다는 점이 장점이자 한계다 |
| **말버릇이 옮는다** | 학생이 "Based on the text…"(본문에 따르면…), "Following the example…"(예시를 따라…)처럼 모범 답안을 본 선생님의 말버릇을 배운다. 답변 앞 몇 토큰을 학습에서 빼는 임시방편으로 해결했다 |
| **망각이 0은 아님** | 과학 과제에서 지시 따르기가 74.3 → 66.8로 여전히 떨어졌다. SFT(35.3)에 비하면 훨씬 낫지만 완벽하지는 않다 |

---

## 6. 꼼꼼히 읽으면 보이는 것

논문을 그대로 받아들이기 전에 알아둘 점들이다.

**① 이론과 실제 구현이 다르다.** 논문은 "학생이 선생님을 따라가는 방향"을 수학적으로 설명할 때 **reverse KL**이라는 특정 방식을 전제한다. 그런데 저자들은 v2와 코드 저장소에서 "**실제 결과는 모두 forward KL로 학습했다**"고 정정했다. 두 방식은 "두 분포의 차이를 어느 쪽에서 재느냐"가 다르다. 쉽게 말해, **실험 결과는 믿을 만하지만 "왜 되는가"에 대한 논문의 이론 설명은 실제 학습 방식과 딱 맞지는 않는다.** "학생이 자기 답으로 배운다"는 핵심은 두 경우 모두 같다.

**② 비교 대상이 빠져 있다.** 강화학습(GRPO), 예전 데이터를 섞어 복습시키는 방법(replay), LoRA, "원래 모델에서 너무 멀어지지 말라"는 벌점을 준 SFT와의 비교가 없다. 특히 마지막 것은 "효과가 온폴리시 때문인가, 그냥 멀어지지 않게 막은 덕분인가"를 가를 수 있는 비교라 아쉽다.

**③ 실험 규모가 작다.** 주 실험은 Qwen2.5 한 계열의 14B 이하 모델이다. 지식 실험은 문서 9개로, 질문 생성과 채점을 모두 GPT-5 계열 모델이 했다.

**④ 학회 게재 여부.** 인터넷에서 "ICML 2026 논문"으로 소개되곤 하지만, arXiv와 논문 PDF, 프로젝트 페이지에서는 게재 표기를 확인할 수 없다.

그래도 **"방법은 단순한데 결과는 강하다"**는 평가는 유효하다. 특히 "더 배우면서 덜 잊는다"와 "답만 있는 데이터로 추론 모델을 개선한다"는 실무에서 바로 쓸 만한 결과다.

## 7. 이후 연구 한눈에 보기

논문이 나오고 반년 사이에 인용한 논문이 약 200편 쌓였다(2026-09 기준). 초심자가 알아둘 만한 것만 추렸다.

| 논문 | 한 줄 |
|---|---|
| **SDPO** ([2601.20802](https://arxiv.org/abs/2601.20802)) | 같은 저자진의 **자매 논문**. 모범 답안 대신 **실행 결과(에러 메시지, 실패한 테스트)**를 선생님에게 보여준다. 코딩 벤치마크 LiveCodeBench에서 RL(GRPO) 41.2% → 48.8% |
| **When Does Continual Learning Require Learning** ([2607.07847](https://arxiv.org/abs/2607.07847)) | 여러 지속학습 방법을 한자리에서 비교했다. SDFT가 순차 학습에서 **유일하게 모든 과제를 원래 수준 이상으로 유지**했다. 대신 **이미 아는 사실을 새 사실로 바꾸는 일**(예: 바뀐 통계 수치)에는 약했다 |
| **Can a LM Learn Facts Continually?** ([2607.11020](https://arxiv.org/abs/2607.11020)) | 비슷한 방식을 **20번 반복**해 사실을 계속 추가하면, 선생님을 "누적 학습된 모델"로 둘 때 무너진다. 선생님을 **원래 모델로 고정**해야 버틴다 |
| 비판 연구들 (SDPO·수학 추론 대상) | 답변의 **다양성이 줄어든다**, 모델이 **전혀 못 푸는 과제**에서는 배울 신호가 약하다 등의 약점이 보고됐다 |

## 8. 정리

```
  문제    파인튜닝(SFT)하면 새 기술은 배우지만 원래 능력을 잊는다
          원인: 남이 쓴 답을 그대로 베끼느라 원래 모습에서 멀리 벗어남
            │
  아이디어  모범 답안을 본 "나 자신" = 선생님
          내가 쓴 답을 선생님이 한 단어씩 첨삭 (온폴리시)
          선생님은 나를 아주 천천히 따라옴 (EMA)
            │
  왜 되나   선생님은 과제를 100% 풀면서도 원래 모델과 가깝다
          (KL 0.68, SFT 결과물은 1.26)
            │
  결과    새 과제: SFT보다 높음 (과학 70.2 vs 66.2 등)
          기존 능력: 거의 유지 (64.5~65.4, 원래 65.5, SFT 53.4~60.2)
          새 지식: 간접 질문 98점 (SFT 80)
          여러 기술 순차 학습: 차곡차곡 쌓임
            │
  한계    학습 시간 약 4배 · 7B 이상 필요 · 큰 행동 변화는 불가
          이론(reverse KL)과 실제 구현(forward KL)이 다름
```

**언제 써 볼 만한가?**
- 7B 이상 모델에게
- 모범 답안(데모)은 있지만 자동 채점 기준은 없는 과제를
- 기존 능력을 해치지 않고 가르치고 싶을 때

## 부록: 수식으로 보기

궁금한 사람을 위한 부분이다. 건너뛰어도 본문 이해에는 지장이 없다.

**학습 목표.** $x$는 질문, $c$는 모범 답안, $\pi_\theta$는 학생, $\pi(\cdot\mid x,c)$는 모범 답안을 본 선생님이다. 논문의 식은 학생이 만든 답 $y$ 위에서 두 분포의 차이를 줄이는 것이다.

$$
\mathcal{L}(\theta) = \mathbb{E}_{y\sim\pi_\theta(\cdot\mid x)}\left[\log\frac{\pi_\theta(y\mid x)}{\pi(y\mid x,c)}\right]
$$

$y$를 **학생이 샘플링**한다는 점(온폴리시)이 SFT와의 결정적 차이다. SFT는 $y$ 자리에 모범 답안 $c$를 그대로 넣는다. (6절에서 말했듯 실제 실험에서는 토큰마다 방향을 바꾼 forward KL을 썼다.)

**"숨은 점수표" 해석.** 논문은 이 학습이 다음과 같은 **토큰별 보상**으로 RL을 하는 것과 같다고 보인다.

$$
r_t = \log\frac{\pi(y_t\mid \cdot, c)}{\pi_k(y_t\mid \cdot)}
$$

모범 답안을 본 내가 그 단어를 **더** 쓰고 싶어 하면 양수, **덜** 쓰고 싶어 하면 음수다. 점수표를 따로 만들지 않아도 "모범 답안을 본 나"와 "지금의 나"의 차이가 곧 점수표가 된다. 이것이 **"보상 없이 RL처럼 배운다"**의 정체다.

**선생님 업데이트 (EMA).** $\phi$는 선생님 가중치다.

$$
\phi \leftarrow 0.01\,\theta + 0.99\,\phi
$$
